# Site templates

`index.html` (home page) and `privacy.html` (privacy policy) are the two pages Google requires to publish the OAuth app. Replace `ВАША_ПОЧТА@gmail.com` with your contact email, host both files publicly (for example GitHub Pages) and put their URLs into Google Cloud → Google Auth platform → Branding. See [../SETUP.en.md](../SETUP.en.md).
