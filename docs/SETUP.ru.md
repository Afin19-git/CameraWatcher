# Настройка: сборка, ключ подписи, Google Drive

[English](SETUP.en.md) · **Русский** · [Українська](SETUP.uk.md)

## 1. Сборка

1. Установите Android Studio (Koala 2024.1 или новее). В неё встроен JDK 17.
2. *File → Open*, выберите папку проекта, дождитесь синхронизации Gradle.
3. Подключите телефон с отладкой по USB и нажмите *Run* или выберите *Build → Build APK(s)*.

Нужен Android 7.0 (API 24). Зависимости: `play-services-auth` (вход в Google Drive) и, для источника камеры «USB-веб-камера», `libausbc` с JitPack — при первой синхронизации Gradle нужен доступ к jitpack.io.

## 2. Подпись своим ключом

1. Создайте ключ один раз. В Android Studio: *Build → Generate Signed App Bundle / APK → Create new…*, или в терминале:
   `keytool -genkeypair -v -keystore camerawatcher.jks -alias camerawatcher -keyalg RSA -keysize 2048 -validity 36500`
   В Windows `keytool` лежит внутри Android Studio: `C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe` (в PowerShell запускайте с `&` в начале).
2. Скопируйте `keystore.properties.example` в `keystore.properties` и заполните. В `storeFile` используйте прямые слэши.
3. Синхронизируйте Gradle. Теперь и *Run*, и *Build APK* подписываются вашим ключом, поэтому SHA-1 у отладочной и релизной сборки одинаковый.
4. Релизная сборка: `./gradlew assembleRelease`, файл `app/build/outputs/apk/release/app-release.apk`. Переименуйте его в `CameraWatcher-<версия>.apk` для релиза на GitHub.

**Никогда не выкладывайте и не пересылайте файл ключа и `keystore.properties`.** `.gitignore` закрывает `*.jks`, `*.keystore` и `keystore.properties`; если ваш файл ключа называется иначе, добавьте его. Сделайте резервную копию: без ключа обновления выпустить не получится.

Поверх сборки, подписанной другим ключом, установить нельзя: сначала удалите старое приложение (настройки и локальные клипы пропадут, файлы на Drive останутся).

## 3. Вход в Google Drive

Google Play Services опознают приложение по имени пакета и SHA-1 подписи, поэтому на каждый ключ нужен свой OAuth-клиент.

1. Откройте <https://console.cloud.google.com> и создайте проект.
2. *APIs & Services → Library*: включите **Google Drive API**.
3. *Google Auth platform*:
   - **Branding**: название, почта поддержки, **главная страница приложения** и **ссылка на политику конфиденциальности** (обе обязательны для публикации). Шаблоны этих страниц лежат в `docs/site/`; разместите их где угодно публично, например на GitHub Pages, и замените контактную почту. Добавьте домен страниц в *Authorized domains* (для GitHub Pages: `имя.github.io`). Логотип не загружайте: он запускает проверку бренда, для которой нужен собственный подтверждённый домен.
   - **Audience**: *External*, затем **Publish app**, чтобы статус стал *In production*. В режиме *Testing* Google сбрасывает вход каждые 7 дней. Приложение просит только `drive.file`, это не чувствительный доступ, поэтому проверка Google не нужна.
4. *Clients → Create client → Android*: имя пакета `com.camerawatcher` и SHA-1 вашего ключа. Установленное приложение показывает его в *Настройки → Google Drive* (нажатием копируется); или выполните `keytool -list -v -keystore <файл> -alias <alias>`.
5. Подождите 5–10 минут, затем *Настройки → Google Drive → Войти через Google*. Google напишет, что не проверял приложение: *Дополнительно → Перейти на CameraWatcher*.

Если в форке меняете `applicationId`, создайте клиент для нового имени пакета.

## Если что-то не работает

- **Ошибка 10 / «приложение не найдено»**: имя пакета или SHA-1 в клиенте не совпадают с установленной сборкой, или клиент создан пару минут назад.
- **Вход слетает раз в неделю**: приложение всё ещё в режиме *Testing*, опубликуйте его.
- **`keytool` не распознан**: используйте полный путь (пункт 2.1).
- **Gradle не может найти `com.github.WojciechCzeronko.AndroidUSBCamera:libausbc` (или `libuvc`)**: проверьте доступ к jitpack.io (корпоративные сети иногда его блокируют) и что тег `3.6.0-lowlatency1` всё ещё существует в этом репозитории на GitHub — если его переименовали или удалили, откройте страницу Releases/Tags репозитория, возьмите актуальный тег и обновите версию в **обеих** строках зависимостей в `app/build.gradle.kts` (они должны совпадать).
- **Unresolved reference: `USBMonitor` (или похожее) в `UsbCameraSource.kt`**: `libausbc` подключает модуль `libuvc` у себя внутри как `implementation`, а Gradle не передаёт такие зависимости дальше тем, кто подключает только `libausbc` — `libuvc` нужно подключать отдельной строкой (в этом проекте уже сделано; если будущая правка её уберёт, сборка снова сломается по этой же причине).
- **Play Protect предупреждает**: ожидаемо для фоновой службы камеры не из Google Play. *Подробнее → Всё равно установить*.
- **Папки на Drive на «не том» языке**: названия фиксируются при входе. Выйдите и войдите заново после смены языка, чтобы перейти на новое дерево папок (старые файлы останутся в старом).
